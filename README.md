# Cuffed: Fabric Edition

Handcuffs, chains, keys, and lockpicking for Minecraft roleplay. Cuffed: Fabric Edition is an unofficial port of Cuffed from Forge 1.20.1 to Fabric on Minecraft 26.2.

## Features

- Restrain and escort players, search their inventories, and confiscate items.
- Craft keys, carry them on key rings, make copies with key molds, and pick locks.
- Build detention areas with pillories, chain anchors, and prison bunks.
- Craft the Warden’s Guide from a book and an iron nugget for in-game instructions.

## Installation

1. Set up Minecraft 26.2 with Fabric Loader 0.20.1 or newer and Java 25 or newer.
2. Download the mod JAR from [GitHub Releases](https://github.com/mishtok125/cuffed-fabric-edition/releases) and get [Fabric API for Minecraft 26.2](https://modrinth.com/mod/fabric-api).
3. Place both JARs in the `mods` folder. For multiplayer, install both on the server and on each client.

## Building from source

Use JDK 25 and run `./gradlew build` on Linux or macOS, or `.\gradlew.bat build` on Windows. The mod JAR is written to `build/libs/`.
