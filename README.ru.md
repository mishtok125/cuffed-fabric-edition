# Cuffed: Fabric Edition

[English](README.md) · Русский

Наручники, цепи, ключи и взлом замков для ролевой игры в Minecraft. Cuffed: Fabric Edition — неофициальный порт Cuffed с Forge 1.20.1 на Fabric для Minecraft 26.2.

## Возможности

- Надевайте наручники, сопровождайте игроков, обыскивайте их и изымайте предметы.
- Создавайте ключи, носите их на связке, отливайте копии по формам и вскрывайте замки.
- Обустраивайте места содержания с колодками, креплениями для цепей и тюремными койками.
- Сделайте руководство надзирателя из книги и железного самородка, чтобы открыть инструкции прямо в игре.

## Установка

1. Установите Minecraft 26.2 с Fabric Loader 0.20.1 или новее и Java 25 или новее.
2. Скачайте JAR мода из [GitHub Releases](https://github.com/mishtok125/cuffed-fabric-edition/releases) и [Fabric API для Minecraft 26.2](https://modrinth.com/mod/fabric-api).
3. Поместите оба JAR в папку `mods`. Для сетевой игры установите их на сервер и на клиент каждого игрока.

## Сборка

Установите JDK 25 и запустите `./gradlew build` на Linux или macOS либо `.\gradlew.bat build` на Windows. Готовый JAR появится в `build/libs/`.
